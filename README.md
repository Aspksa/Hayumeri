# Hayumeri

Начальная локальная веб-версия проекта на TypeScript, Vite и Node.js.

## Запуск на Windows

1. Скачайте репозиторий целиком и распакуйте в любую папку или на внешний SSD.
2. Дважды щёлкните `Hayumeri.bat`.
3. При первом запуске потребуется интернет для установки npm-зависимостей. Если подходящего Node.js нет, загрузится портативный Node.js 22.16.0 с официального сайта с проверкой SHA-256.
4. Браузер откроет локальный адрес (обычно `http://127.0.0.1:5173`). Если порт занят, Vite выберет другой.
5. Для остановки нажмите `Ctrl+C` в окне запуска.

Права администратора не нужны; скачанные файлы находятся в `.runtime/`, npm-зависимости — в `node_modules/`, журнал запуска — `logs/launch.log`. Эти директории не отправляются в GitHub. Скрипт не изменяет системные настройки, не завершает другие процессы и не обновляет код приложения.

## Разработка

```bash
npm install
npm run dev
npm run build
npm test
```

**Текущее состояние:** создан только рабочий стартовый каркас. Модули приложения и система обновлений ещё не реализованы.
