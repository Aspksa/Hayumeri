# Рабочие пространства Hayumeri

Hayumeri теперь содержит единую чёрно-золотую оболочку с навигацией по разделам. Содержимое разделов загружается без перезапуска локального сайта.

## Готовые функции

- **Заметки**: создание, редактирование, поиск, сохранение по кнопке и удаление с подтверждением. При попытке уйти с изменённой заметки выводится предупреждение.
- **Задачи**: добавление, отметка выполнения, фильтры «Все / Активные / Завершённые», удаление с подтверждением. Каждое действие сохраняется на диск.
- **Обновления**: штатная кнопка в верхней панели сохранена, а из «Системы» можно открыть то же окно.
- **Навигация**: все рабочие пространства доступны из бокового меню; на узком экране оно становится горизонтальным списком. Адрес с `#notes` или `#tasks` можно открыть напрямую.

## Где находятся данные

Заметки и задачи хранятся **локально в папке установленного проекта**:

- `.runtime/workspace-data.json` — текущие записи, формат JSON со схемой и номером ревизии;
- `.runtime/workspace-data.previous.json` — резервная копия файла перед последним успешным изменением.

Эти файлы не отправляются в GitHub и не включены в коммиты. Папка `.runtime` защищена локальным обновлятором. Изменение рабочего порта браузера не меняет хранилище.

Перед ручным переносом или переустановкой проекта обязательно сделайте копию **всей `.runtime`**, а также пользовательских файлов и секретов. Резервная копия предыдущей версии — не замена полноценному версионированному бэкапу.

При невозможности сохранения сервер сообщает об ошибке. Если файл данных повреждён, он **не заменяется пустым** автоматически. Используйте копию и разберитесь с причиной повреждения.

## Ограничения первого этапа

- Заметки **не автосохраняются**: необходимо нажимать «Сохранить».
- Хранилище рассчитано на одного локального пользователя; устаревшие изменения из другой вкладки отклоняются. Одновременная запись из нескольких отдельных серверов в одну папку не поддерживается.
- Не более 500 заметок, 2000 задач, 200 символов в заголовке, 100 000 символов в тексте одной заметки. Максимальный размер одного запроса — 1,5 МБ.
- Нет импорта/экспорта, корзины и синхронизации между компьютерами.
- Разделы **«Знания», «Память», «Граф связей», «Агенты», «Чат», «Диск»** и функциональная диагностика «Системы» пока являются оформленными пространствами **без подключённых сервисов**. Они явно сообщают об этом и не показывают искусственных результатов.
- MongoDB, Redis, Neo4j и Qdrant продолжают запускаться отдельно через `Hayumeri-DB.bat`; в интерфейсе пока нет реального подключения к ним.
- Встроенное хранилище доступно при обычном локальном запуске Vite/BAT. Простой статический экспорт `dist` без сервера его не предоставляет.

## Безопасность и проверка

Сохранение доступно только при запросе с локального источника `127.0.0.1` с проверкой `Origin`, заголовка действия и JSON. Данные валидируются по структуре и размерам; номера ревизий предотвращают тихую перезапись устаревших записей в пределах одного сервера. Перед заменой файла выполняется копирование предыдущих данных. Это не полноценная защита от вредоносных локальных программ и не шифрование данных.

Windows CI проверяет создание заметки и задачи через HTTP, сохранение файла, чтение, обновление задачи, конфликт ревизий, запрет записи без Origin, создание резервной копии, запуск BAT и установку обновления.
