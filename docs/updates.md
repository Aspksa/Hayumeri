# Обновление Hayumeri из GitHub

После запуска через Hayumeri.bat нажмите круглый значок обновлений в правом верхнем углу сайта.

1. Нажмите «Проверить GitHub». Появятся установленная версия, последний коммит ветки main и описание изменений.
2. Нажмите «Установить обновление» и подтвердите действие. Приложение временно остановит сайт.
3. Установщик скачает архив конкретного коммита, прочитает Git-дерево через GitHub API и сверит Git SHA-1 каждого файла с соответствующим blob в дереве.
4. Перед изменением файлов создастся резервная копия в .runtime/updates/backup-.../. Архив сначала проверяется и распаковывается во временную папку. Подозрительные пути и слишком большие файлы отклоняются.
5. Установщик запустит Hayumeri.bat заново и проверит HTTP-ответ нового сайта. При ошибке восстановит предыдущие файлы и запустит старую версию.

## Защита данных

Никаких прав администратора не требуется. Пользовательские папки vault/, data/, documents/, uploads/, storage/, disk/, node_modules/, .runtime/, logs/ и Docker-тома NoSQL не перезаписываются. Локальные файлы .env и .env.*, а также настройки config/launcher.json сохраняются. Посторонние файлы в папке проекта не удаляются.

Автоматическое применение доступно при запуске через Hayumeri.bat из обычной папки на Windows. Для Git-клона используйте git pull, чтобы не перезаписывать незакоммиченные изменения.

Доступ к GitHub нужен для проверки и установки. Установленная ревизия хранится в .runtime/update-state.json; текущий статус в .runtime/update-progress.json, журнал в .runtime/update.log. Резервные копии сохраняются, пока их не удалит владелец.

## Ограничения

Механизм сверяет Git-объекты по HTTPS с GitHub API. Отдельной криптографической подписи релиза пока нет. Если компьютер выключится прямо во время замены файлов, ручное восстановление может потребоваться из сохранённой папки backup. Обновление пользовательских данных, схемы баз и Docker-образов не выполняется: они управляются отдельно.

При запуске командой npm run dev окно умеет проверить GitHub, но установка через интерфейс заблокирована, потому что без BAT нет безопасного сценария перезапуска.

Важное предупреждение: обновление заменяет исходные файлы, которые входят в репозиторий. Если вы вручную меняли код установленной копии, сделайте собственную резервную копию перед обновлением.
